# Knowledge Quality Benchmark

This benchmark validates whether the V5 public knowledge boundary produces coherent design-engineering behavior after private and historical sources are removed from the runtime surface.

It evaluates four separated dimensions:

- Source quality: removed raw or superseded material must have admitted maintained replacements.
- Retrieval quality: scoped search must return relevant maintained guidance or an explicit no-match gap.
- Rule quality: compiled rules must retain source IDs, model links, conflict precedence, and no private fallback.
- Product outcome: shadow-model traces must preserve task, state, information, component, token, accessibility, verification, and evidence decisions.

The benchmark is an engineering gate. It is not a legal opinion and does not approve external source reuse.
